# linkle.space 文档站

linkle.space 用户文档，VitePress 构建，私有维护。

## 技术栈

| 层 | 技术 |
|----|------|
| 框架 | VitePress |
| 包管理 | pnpm |
| 构建 | Vite + esbuild |

## 快速开始

```bash
pnpm dev      # 本地开发
pnpm build    # 生产构建
pnpm preview  # 预览构建结果
```

## 结构

```
index.md          — 首页（hero layout）
guide/            — 使用指南
api/              — API 参考
deployment/       — 部署运维
.vitepress/       — VitePress 配置
```
